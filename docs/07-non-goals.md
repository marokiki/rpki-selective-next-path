# Non-goals for the initial implementation

- Defining a final ASN.1 transition object.
- Updating RFC 9691 or claiming compliance with an unspecified extension.
- Implementing a production RP policy.
- Implementing a production Hosted RPKI service.
- Implementing PQ signature algorithms.
- Making CCR a mandatory dependency.
- Solving secure out-of-band enrollment for an unprepared Delegated CA after compromise.
- Modeling BGPsec UPDATE signatures.
- Reproducing the complete global RPKI in Phase 1.
- Treating synthetic timing estimates as operational measurements.
